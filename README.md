# 🛍️ Hexa-Shop

**Hexa-Shop** is a modern, responsive e-commerce website built to showcase and sell fashion products online. The project focuses on clean design, easy navigation, and a smooth shopping experience.

---

## 🌟 Features

- Responsive layout for all devices (mobile, tablet, desktop)  
- Product listing with images, names, and prices  
- Interactive hover effects  
- Clean and minimal UI design  
- Category-based product filtering  
- Easy navigation through header and footer menus  

---

## 🛠️ Technologies Used

- **HTML5** – for structure  
- **CSS3** – for styling and layout  
- **Bootstrap** – for responsiveness and modern design  
- **JavaScript** – for interactivity
